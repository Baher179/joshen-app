# Joshen — جوشن

نموذج تفاعلي (prototype) لتطبيق جمال منزلي بالعربية (RTL)، يغطي ثلاثة تطبيقات في واجهة واحدة:
**العميلة** · **مقدّمة الخدمة** · **المندوب**.

🔗 **تجربة مباشرة:** https://joshen-app-baher.vercel.app

## المزايا

- حجز فردي كامل: تصنيف ← خدمة ← مقدّمة الخدمة ← الموعد ← المراجعة ← الدفع
- **حجز مجمّع**: عدة أشخاص في موعد واحد ومكان واحد، لكل شخص خدماته وإضافاته،
  مع ضمان أن جميع الخدمات تُنفّذ بواسطة مقدّمة خدمة واحدة
- باقات (packages) بأسعار وخصومات
- تطبيق مقدّمة الخدمة: المواعيد، تفاصيل الطلب المجمّع، التسعير، الأرباح
- تطبيق المندوب: الرحلات والأرباح
- محفظة، كوبونات، تتبّع الطلب، محادثة، تقييمات، إشعارات

## التشغيل محلياً

الملفات تحتاج سيرفر محلي (الفتح المباشر للملف لن يحمّل الأصول):

```bash
cd joshen-app
python3 -m http.server 8000
```

ثم افتح http://localhost:8000/Joshen%20App.dc.html

## بنية المشروع

| المسار | الوصف |
| --- | --- |
| `joshen-app/Joshen App.dc.html` | المصدر الوحيد — الشاشات والبيانات والمنطق |
| `joshen-app/support.js` | الرنتايم الذي يرسم الصفحة (يحمّل React تلقائياً) |
| `joshen-app/_ds/` | نظام التصميم: مكوّنات، ألوان، خطوط |
| `joshen-app/art/` | الصور والرسومات التوضيحية |
| `joshen-app/brand/` | شعارات جوشن |

التعديل يتم في `Joshen App.dc.html` ثم إعادة تحميل الصفحة.

## ملاحظات

- هذا نموذج واجهة للعرض — لا يوجد باك-إند، والبيانات كلها تجريبية داخل الملف.
- لا توجد مدفوعات حقيقية؛ شاشات الدفع محاكاة.
